# Reranking

重排是二段式检索的第二阶段：第一阶段追求召回覆盖，第二阶段追求排序精度。

## Cross-Encoder

交叉编码器把查询和候选段落拼成一次前向计算，输出相关性分数。精度显著高于双塔嵌入，因为查询与文档在注意力层中充分交互。代价是每个候选都要一次前向计算，只能用于第一阶段筛出的少量候选。

## Late Interaction (ColBERT)

Late interaction 折中了双塔与交叉编码器：仍然预计算 token 级向量，但打分发生在检索之后。分数为 maxsim 求和：每个查询 token 取其与段落所有 token 的最大相似度，再求和或取均值。它比单向量表示保留了词级匹配能力，对长段落和关键词密集查询尤其有效，且无需模型推理即可离线构建。

## LLM Listwise Reranking

RankGPT 风格的 listwise 重排把一组候选编号后交给 LLM，要求模型直接输出相关性排列。它把排序当作语言任务处理，能捕捉"是否直接回答问题"这类难以用相似度表达的判断。缺点是成本高、对候选顺序敏感，实践中用滑动窗口分批排序来控制长度与偏差。

## 无模型启发式重排

在没有重排模型时，可用词面覆盖度、查询词在段落中的最小覆盖窗口密度、标题命中、块长惩罚组合打分。它便宜、可解释，适合作为兜底通道与调试信号。

## 排序稳定性

重排会破坏第一阶段已经正确的排序，因此常见做法是把重排分数与融合分数加权组合，而不是完全替换。同时保留通道贡献（哪个通道贡献了这个候选）对调试非常关键。
